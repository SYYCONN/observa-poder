# Domínios

Cada domínio será criado quando implementado: `parlamentares/`, `proposicoes/`, `votacoes/`, `financas/`. Dentro dele: `models.py`, `schemas.py`, `service.py` e `router.py` conforme necessidade. Rotas tratam HTTP; serviços concentram regras; modelos descrevem persistência. Evitar camadas vazias e arquivos genéricos como `utils.py`.
